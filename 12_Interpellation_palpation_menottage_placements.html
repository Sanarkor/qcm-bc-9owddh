Interpellation – Palpation de sécurité, menottage, placements, PLI et signalement

QCM Brigadier-chef SUEP 2026 – 20 questions, une ou plusieurs bonnes réponses. Notation tout ou rien.

Q1. La palpation de sécurité :

Réponse : B, C
Pas de consentement nécessaire ; mesure peu intrusive sans fouille ni retrait de vêtement.
Source : Instruction DGPN/DGGN – pratique des palpations de sécurité ; TDI – La palpation de sécurité (vs 06-2021)

Q2. La palpation de sécurité peut être pratiquée de manière plus systématique :

Réponse : B, C, D
Sur réquisitions (78-2 al. 2 et 3), il faut des éléments démontrant une dangerosité potentielle.
Source : TDI – La palpation de sécurité (vs 06-2021) ; Instruction DGPN/DGGN – pratique des palpations de sécurité

Q3. La palpation de sécurité est obligatoirement réalisée par une personne de même sexe s'agissant :

Réponse : D
Obligatoire pour les gardés à vue (et certaines personnes retenues) ; ailleurs « chaque fois que possible ».
Source : Instruction DGPN/DGGN – pratique des palpations de sécurité

Q4. Dans le déroulement d'une palpation de sécurité, la première étape consiste à :

Réponse : B
Remise volontaire, puis moyens de détection, puis information, puis palpation.
Source : Instruction DGPN/DGGN – pratique des palpations de sécurité

Q5. Lors d'une palpation, la fiche TDI recherche, chaque fois que les circonstances le permettent :

Réponse : A
Bras levés, appuis, amené au sol : démonstrations ostensibles à éviter.
Source : TDI – La palpation de sécurité (vs 06-2021)

Q6. Toute dérogation au principe de palpation par une personne de même sexe :

Réponse : C
Hormis situations exceptionnelles (dangerosité, urgence), avec justification détaillée.
Source : TDI – La palpation de sécurité (vs 06-2021)

Q7. Selon l'article 803 du CPP, le port des menottes n'est possible que si la personne est considérée :

Réponse : A, D
Mesures utiles aussi pour éviter qu'elle soit photographiée ou filmée.
Source : TDI – Menottage (vs 01-2022) ; Note DGPN 13/09/2004 – utilisation des menottes

Q8. Le menottage :

Réponse : A, B, C
Il ne doit en aucun cas être systématique ; tout incident (blessure) est mentionné en procédure.
Source : TDI – Menottage (vs 01-2022) ; Note DGPN 13/09/2004 – utilisation des menottes

Q9. Concernant la technique de menottage, quelles affirmations sont exactes ?

Réponse : A, B, D
Le creux lombaire est à proscrire (blessures en cas de chute sur le dos).
Source : TDI – Menottage (vs 01-2022)

Q10. Lors de la préhension, la menotte est saisie fermement sur :

Réponse : B
La partie mobile est ensuite apposée sur le poignet, entre la main et l'avant-bras.
Source : TDI – Menottage (vs 01-2022)

Q11. L'agent chargé du menottage s'approche de l'individu debout lorsque :

Réponse : D
Placer l'individu contre un appui peut mettre le dispositif en danger.
Source : TDI – Menottage (vs 01-2022)

Q12. Dès les menottes posées, le policier :

Réponse : A
Même si les circonstances repoussent la palpation complète.
Source : TDI – Menottage (vs 01-2022)

Q13. Chef de patrouille, vous devez effectuer un contrôle puis une palpation ; contexte favorable, situation figée. Le placement prescrit est :

Réponse : B
Binôme réuni : analyse/patrouille ; binôme contact : contexte défavorable ou incertain.
Source : TI – Les placements (vs 12-2022)

Q14. Le binôme réuni est prescrit :

Réponse : D
Côte à côte, à environ une longueur de bras ; permet de basculer vers le schéma le plus opérant.
Source : TI – Les placements (vs 12-2022)

Q15. En binôme contact, l'agent arrière :

Réponse : A
L'agent avant focalise sur le tiers ; l'agent arrière est en retrait de son côté faible, main ou coude sur l'épaule.
Source : TI – Les placements (vs 12-2022)

Q16. Triangulation latérale : l'individu se déplace. Pour éviter de rendre inopérants les axes de tir :

Réponse : B
Inconvénients : topographie, axes de tir, éloignement.
Source : TI – Les placements (vs 12-2022)

Q17. Selon la fiche PLI, la répartition des rôles Protection / Liaison / Interpellation :

Réponse : D
Le dispositif peut ensuite évoluer selon la situation.
Source : TI – Protection, liaison, interpellation (PLI)

Q18. Concernant la PLI, quelles affirmations sont exactes ?

Réponse : A, B, D
« Aucune intervention de police n'est envisageable sans protection ».
Source : TI – Protection, liaison, interpellation (PLI)

Q19. Dans la fiche « Points clés du signalement », la rubrique n°10 regroupe :

Réponse : B
Visage = 09, voix = 11, habillement = 12.
Source : TI – Points clés du signalement

Q20. Dans la même fiche, la rubrique n°12 correspond à :

Réponse : C
09 visage, 10 démarche/silhouette/gestuelle, 11 voix, 12 habillement.
Source : TI – Points clés du signalement
